# LSI System & Convolution Simulator

An interactive Python-based simulator for Signal and Systems.

## Features
- Input Signal Generation
- Impulse Response Generation
- Linear Convolution
- Step Response Visualization
- Causality Analysis
- Stability Analysis
- Continuous-Time and Discrete-Time Signals
- Time Shifting and Scaling
- Phase Adjustment
- CSV Data Download

## Technologies Used
- Python
- Streamlit
- NumPy
- SciPy
- Matplotlib
- Pandas

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Project

streamlit run project.py

## Project Purpose

This project helps students understand
Linear Shift Invariant Systems and
Convolution through interactive graphs.
